# MoveTopia 使用说明书

版本 0.1.0 · 2026-11-08。

## 打开

使用管理者部署后提供的网站地址，无需登录、安装软件或提供 API 密钥。推荐现代 Chrome、Edge、Safari；手机打开同一链接。语音依赖设备与浏览器，主流程不依赖外部生成服务。

## 一分钟演示

1. 首页点击「开始 10 分钟练习」→「使用示例，开始练习」。
2. 尝试暂停 / 继续，随后点击「结束练习，进入拍照」，无需等满 10 分钟。
3. 点击「3 秒倒计时拍摄」，3 → 2 → 1 后自动进入选片。
4. 选择照片 02 →「生成瑜伽大片」，等待模拟任务结束。
5. 结果应仍为照片 02。可以放大查看，或下载 PNG。

## 页面说明

| 页面 | 操作和反馈 |
| --- | --- |
| 首页 | 桌面左侧 / 手机顶部导航，主按钮进入练习说明。样片明确标注为示例。 |
| 练习说明 | 阅读入镜与隐私说明，开始示例练习或直接拍照。 |
| 练习 | 计时、暂停、继续；可提前结束进入拍照。没有真实动作识别或动作评分。 |
| 全屏取景 | 示例画面铺满屏幕，主动开启语音后朗读提示；当前画面不是直播。 |
| 倒计时 | 自动推进，可取消。结束后展示三张预置样片，并清空旧选片。 |
| 选片 | 点击照片行，描边和勾选表示当前选择。未选择时不能生成。 |
| 生成 | 展示模拟等待，没有真实 AI 处理，也不显示虚构真实百分比。 |
| 结果 | 当前所选原图，可放大 / 下载，不冒充真实 AI 生成结果。 |
| 作品示例 | 三张风格示例，点击可带着选择进入选片。 |

## 异常流程演示

- 取景页「入镜状态演示」：选择边缘遮挡 / 无人入镜，拍摄按钮禁用；恢复完整入镜后继续。这些状态来自手动选择。
- 练习说明「演示选项」：查看摄像头不可用状态，重试返回说明。
- 选片页「演示选项」：勾选生成失败，任务失败后照片不丢失；重试可继续。
- 生成时使用页面导航离开，会弹确认框。浏览器自身后退会直接离开并停止模拟计时。
- 结果页「演示选项」：勾选下一次下载失败，再点下载；重试可发起真实示例下载。

## 下载与数据

下载的是包内的示例 PNG。提示「已发起下载」不等于操作系统已保存，请查看浏览器下载列表；部分手机可能先打开图片预览。

当前版本不访问摄像头、不上传图片、不保存身体关键点。当前标签页仅暂存选片编号，刷新能恢复。关闭标签页后通常清除，但浏览器会话恢复行为依设置而异。计时、语音和任务状态刷新后重置。

## 常见问题

**为什么画面中不是我？** 尚未接入真实摄像头。

**为什么生成前后一样？** 尚未连接生成服务，用原图验证流程。

**为什么没有语音？** 默认关闭，请主动开启；设备需支持中文系统语音，静音或浏览器限制也会影响播放。

**为什么无法打开 localhost？** localhost 只指向自己的电脑。跨电脑分享请使用管理者部署后的地址。

**打开白屏或图片不见了？** 请部署完整 `dist`，保留目录结构，不要只复制 `index.html`；通过 HTTP / HTTPS 打开，不要使用文件双击方式。
