# PR 标题

feat: 交付 MoveTopia 瑜伽写真前端演示与离线部署文档

## 改动说明

新增以瑜伽写真为核心的 React / TypeScript 前端，将首页、练习、全屏取景、倒计时、选片、模拟生成、结果和下载连成可运行流程。选中照片会在生成、结果、下载和刷新后保持一致；桌面保留侧栏，手机使用顶部导航和纵向卡片。

功能区采用灰白黑、清晰边框和按钮反馈。补齐未选中禁用、入镜提醒演示、权限受阻说明、生成失败 / 重试、处理中禁用、离开确认和下载失败 / 重试。

为无法访问 GitHub 的接收方提供便携静态构建、完整源码、Nginx 配置示例、无需 npm 的静态预览脚本，以及使用说明、前端架构、后端交接和接口草案。静态图片使用 Vite 基路径，支持子目录部署。

## 功能边界

- 摄像头画面、入镜检测和 AI 生成仍是明确标注的演示。
- 结果为当前所选原图；下载的是包内示例 PNG。
- 不包含用户照片上传、登录、服务端存储或付费 API 请求。
- 后端接口文档是待确认提议，不表示服务已实现。
- 不包含旧方案的游戏解救、伙伴、积分和奖励。

## 验证

- TypeScript 与 Vite 构建。
- 发布资源路径、脚本、样式、三张 PNG 完整性检查。
- 实际浏览器验证：计时 / 暂停、倒计时、选片、失败重试、结果一致性、离开确认和下载。
- 主要页面在 320 / 390 / 768 / 1440 px 无文档级横向溢出或图片加载失败。
- 最终离线包的校验与根路径 / 子目录预览结果见 `verification/交付验收.md`。
